# Governance

Summary of docs/09 (the full text is authoritative until this file is expanded).

- **Roles:** maintainers (merge rights per area, see `.github/CODEOWNERS`), core team, security team, release managers.
- **Decisions:** lightweight ADRs in `docs/adr/`. Lazy consensus (72 h) for normal changes; maintainer supermajority for core-surface, protocol and policy changes.
- **Plugin SDK breaking changes:** RFC process, with at least a 6-month deprecation window.
- **Foundation:** a nonprofit is planned. Until it exists the project is run by its founding maintainers; a fiscal sponsor will be pursued first (docs/09 section 1). Trademarks and release-signing keys will transfer to the Foundation when it is established. Sponsors receive recognition only, never roadmap or security-disclosure control.
- **Inactive maintainers** lapse after 12 months.
