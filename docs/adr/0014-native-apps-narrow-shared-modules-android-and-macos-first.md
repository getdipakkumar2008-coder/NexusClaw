# ADR-0014: Native apps, narrow shared modules, Android and macOS first

- Status: Accepted (owner approval of defaults, Phase 0)
- Date: 2026-10-16

## Decision
Apps are genuinely native and share only narrow modules; Android and macOS ship before iOS, Windows and Linux.

## Rationale and consequences
Quality and platform fit; sequencing limits staffing risk.
